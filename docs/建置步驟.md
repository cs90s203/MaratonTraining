## 妳要做的：Firebase 設定（一次性，約 10 分鐘）

### 1. 建 Firebase 專案

到 [Firebase Console](https://console.firebase.google.com/) → **新增專案**。
名稱隨意（例如 `marathon-train`）。Google Analytics 可以關掉，用不到。

> 也可以直接用 babylog 那個現有專案，但**建議另外開一個**——訓練資料跟寶寶資料的
> 存取白名單不一樣（教練不該看得到寶寶紀錄），分開比較不會搞混。

### 2. 啟用 Google 登入

**Authentication → Sign-in method → Google → 啟用**，選一個支援信箱，儲存。

### 3. 加入授權網域

**Authentication → Settings → Authorized domains → Add domain**，加入：

```
cs90s203.github.io
```

（`localhost` 預設就在清單裡，不用加。）

### 4. 建立 Firestore 資料庫

**Firestore Database → 建立資料庫**：

- 模式：**Production mode**（不要選 test mode，那個 30 天後會全部鎖死）
- 地區：**asia-east1**（台灣，離最近）

### 5. 貼上安全規則

**Firestore Database → Rules**，把 [../firestore.rules](../firestore.rules) 的內容整份貼上去，
**先把 email 白名單改好**再按發布：

```javascript
authEmail() in [
  'cs90s203@gmail.com',
  '伴侶的@gmail.com',      // ← 換成真的，全部小寫
  '教練的@gmail.com'
]
```

> ⚠️ **email 一定要全部小寫。** `in [...]` 是精確字串比對，大小寫不同會被當成陌生人擋掉。
> babylog 踩過這個坑，規則檔裡有註解。

### 6. 抄下 firebaseConfig

**專案設定（齒輪）→ 一般 → 你的應用程式 → 新增應用程式 → Web（`</>`）**，
註冊之後會給妳一段 `firebaseConfig`。先存著，CP3 要貼進 `js/firebase-sync.js`。

> 這組設定**本來就是公開的**，可以放心 commit 進 public repo。安全性靠的是上一步的
> Security Rules，不是靠藏這組值。（真正不能外流的是 service account 金鑰，那個 `.gitignore` 已經擋了。）

repo → **Settings → Pages → Source** 選 `main` 分支 / `root` 資料夾 → Save。

等一兩分鐘，網址會是 `https://cs90s203.github.io/MaratonTraining/`。
用手機打開後「加入主畫面」，就會像 App 一樣全螢幕。

## 本機開發

```bash
python3 tools/serve.py
```

開 `http://localhost:8772`。

> ⚠️ **不能直接雙擊 html 檔用 `file://` 開。** Google 登入需要 `http://` 或 `https://`，
> `file://` 會登入失敗。這也是為什麼要有 `serve.py`。
