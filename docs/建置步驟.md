## 妳要做的：Firebase 設定（一次性，約 10 分鐘）

### 1. 建 Firebase 專案 ✅ 已完成

專案：**`mtrain-c655c`**（2026-09-11 建立）

> ⚠️ **一個 Firebase 專案只放一個 App。不要拿既有專案來用。**
>
> 理由不是整齊，是 **Firestore 的 Security Rules 是整個專案共用一份的**。
> 兩個 App 共存時，任何一邊發布規則都可能把另一邊鎖死——資料不會消失，
> 但會全部變成 permission denied，看起來就像資料不見了。
>
> 這件事差點發生：第一次設定時選到了日語學習 App 的專案 `jp-learning-app-a9f2c`
> （`Projects/Language/Released/jp_learning_mvp.html` 在用，路徑是 `users/{uid}/data/…`），
> 而本專案的規則結尾有 `match /{document=**} { allow read, write: if false; }`，
> 貼上去會把日語 App 整個擋掉。已改用新專案。

### 2. 啟用 Google 登入

**Authentication → Sign-in method → Google → 啟用**，選一個支援信箱，儲存。

### 3. 加入授權網域

**Authentication → Settings → Authorized domains → Add domain**，加入：

```
cs90s203.github.io
```

（`localhost` 預設就在清單裡，不用加。）

### 4. 建立 Firestore 資料庫

**Firestore Database → 建立資料庫**：

- 模式：**Production mode**（不要選 test mode，那個 30 天後會全部鎖死）
- 地區：**asia-east1**（台灣，離最近）

### 5. 貼上安全規則

**Firestore Database → Rules**，把 [../firestore.rules](../firestore.rules) 的內容整份貼上去，
**先把 email 白名單改好**再按發布：

```javascript
authEmail() in [
  'cs90s203@gmail.com',
  '伴侶的@gmail.com',      // ← 換成真的，全部小寫
  '教練的@gmail.com'
]
```

> ⚠️ **email 一定要全部小寫。** `in [...]` 是精確字串比對，大小寫不同會被當成陌生人擋掉。
> babylog 踩過這個坑，規則檔裡有註解。

### 6. 抄下 firebaseConfig ✅ 已完成

已存進 [../js/firebase-config.js](../js/firebase-config.js)。

> 這組設定**本來就是公開的**，可以放心 commit 進 public repo。安全性靠的是上一步的
> Security Rules，不是靠藏這組值。（真正不能外流的是 service account 金鑰，那個 `.gitignore` 已經擋了。）

註冊 Web app 時 Console 會問「使用 npm / 使用 `<script>` 標記」——**兩個都不要照抄**。
本專案用 compat SDK（全域 `firebase` namespace，純 `<script src>`，零建置工具），
CP3 會在 `index.html` 加這三行：

```html
<script src="https://www.gstatic.com/firebasejs/12.17.0/firebase-app-compat.js"></script>
<script src="https://www.gstatic.com/firebasejs/12.17.0/firebase-auth-compat.js"></script>
<script src="https://www.gstatic.com/firebasejs/12.17.0/firebase-firestore-compat.js"></script>
```

也不需要 `getAnalytics` 與 `measurementId`。

## 本機開發

```bash
python3 tools/serve.py
```

開 `http://localhost:8772`。

> ⚠️ **不能直接雙擊 html 檔用 `file://` 開。** Google 登入需要 `http://` 或 `https://`，
> `file://` 會登入失敗。這也是為什麼要有 `serve.py`。
